# Second Brain React

เวอร์ชัน React ของเว็บแอป Second Brain สำหรับจัดการชีวิตทุกด้าน

## วิธีรัน

1. cd second-brain-react
2. npm install (ถ้ายังไม่ได้)
3. npm start
4. เปิด http://localhost:3000

## ฟีเจอร์

- บันทึกย่อ, งานที่ต้องทำ, ปฏิทิน, นิสัย, ฐานความรู้
- ใช้ localStorage เก็บข้อมูล
- Reactive UI ด้วย React state

## การพัฒนาต่อ

- เพิ่ม backend ด้วย Firebase หรือ Node.js
- ใช้ library เช่น FullCalendar สำหรับปฏิทินขั้นสูง

สร้างโดย Grok จาก xAI
