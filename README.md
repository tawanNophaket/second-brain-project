# Second Brain Project

โปรเจ็กต์เว็บแอปพลิเคชันสำหรับจัดการชีวิตทุกด้าน เช่น บันทึกย่อ, งานที่ต้องทำ, ปฏิทิน, นิสัย, และฐานความรู้ โดยใช้ HTML, CSS, JavaScript และ localStorage สำหรับเก็บข้อมูล

## วิธีรัน

1. เปิด `index.html` ด้วยเบราว์เซอร์ (เช่น Chrome)
2. ทดสอบฟีเจอร์ต่าง ๆ

## โครงสร้างไฟล์

- `index.html`: หน้าเว็บหลัก
- `css/styles.css`: สไตล์และการออกแบบ
- `js/script.js`: ลอจิกและฟังก์ชัน JavaScript
- `assets/`: สำหรับรูปภาพหรือไฟล์อื่น (ว่าง)

## ฟีเจอร์

- บันทึกย่อ: เพิ่ม/ลบข้อความ
- งานที่ต้องทำ: เพิ่มงาน, เช็คเสร็จ, ลบ
- ปฏิทิน: แสดงเดือน, เพิ่มเหตุการณ์, นำทางเดือน
- นิสัย: เพิ่ม/ลบนิสัย
- ฐานความรู้: พื้นฐาน (ขยายได้)

## การพัฒนาต่อ

- เพิ่ม dark mode
- เชื่อมต่อกับ backend (เช่น Node.js + MongoDB)
- เพิ่มการค้นหา
